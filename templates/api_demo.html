Demonstração da API conectando… LOCAL PROCESSING

A API em funcionamento: envio, fila, mensagens e download

Esta página usa só a API HTTP do serviço, as mesmas rotas que um sistema da organização ou um agente usaria. O documento entra na fila, o progresso vira mensagens e o PDF só é entregue depois que uma pessoa aplica a proteção no portal.

Fluxo

1EnviarPOST /upload

PDF e perfil. Devolve o task_id.

2FilaGET /api/info

Quantos rodam e quantos esperam (limite de tarefas simultâneas).

3MensagensGET /tasks/{id}

Cada mudança de situação vira uma mensagem para quem acompanha.

4Revisão humana/?task={id}

A pessoa confere as tarjas e aplica a proteção. A API não aprova.

5DownloadGET /download/{id}?final=true

409 enquanto não houver aprovação sem pendências.
